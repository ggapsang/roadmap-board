# WOLFPACK 도움말

일정을 시간 위에 늘어놓고 고치는 보드입니다. 세로는 날짜, 가로는 트랙(갈래)이고, 카드 하나가 일정 하나입니다.
편집은 곧바로 저장됩니다.

## 첫 화면

- **보드 목록** — 보드 하나가 프로젝트 하나입니다. 카드를 누르면 그 보드가 열립니다.
- **새 보드** — 오른쪽 위 **새 보드**로 빈 보드를 만듭니다.
- **찾기·정렬** — 위쪽 검색창에 이름을 치면 걸러지고, 옆 목록에서 최근 편집순·이름순을 고릅니다. 보드 카드를
  위아래로 끌면 그 순서가 저장됩니다.
- **복제·이름 변경·삭제** — 각 보드 카드 오른쪽 아이콘입니다. 보드를 지우면 그 보드에만 있던 일정이 함께 지워지고,
  다른 보드에도 있는 일정은 남습니다(지우기 전에 몇 건인지 알려 줍니다).
- **오른쪽 위 아이콘** — 도움말(지금 이 창) · 그래프 · 테마(밝게/어둡게) · 휴지통.

## 탭

- 보드와 그래프는 브라우저처럼 **탭**으로 열립니다. 여러 보드를 동시에 열어 두고 오갈 수 있습니다.
- **+** 로 새 탭(보드 선택)을 열고, 탭의 **×** 로 닫습니다. 탭을 **좌우로 끌면** 순서가 바뀝니다.
- `Ctrl+Tab` / `Ctrl+Shift+Tab` 다음·이전 탭, `Ctrl+T` 새 탭.

## 보드 화면 한눈에

- **위쪽 도구 모음** — 프로젝트 목록 · 일정 검색 · 행 높이(축소/기본/확대) · 글자 크기(가−/가＋) · 설정 ·
  그래프 · 글자 선택 모드 · 되돌리기/다시 실행 · 테마 · 내보내기 · 데이터 · **+ 일정**.
- **요약 줄** — 상태별 개수와 앞으로 2주 안의 마일스톤. 상태나 담당 조직 칩을 누르면 그것만 또렷하게 거릅니다.
- **왼쪽** — 월·주 달력 칸. **가운데** — 트랙마다 세로 칸. 오렌지 가로선이 **오늘**입니다.

## 일정 만들기·옮기기

| 하고 싶은 것 | 방법 |
|---|---|
| 일정 만들기 | 빈 칸을 **클릭**하면 1주짜리가, **끌면** 끈 길이만큼 생깁니다. 도구 모음의 **+ 일정**도 됩니다 |
| 옮기기 | 카드를 끕니다. 위아래는 날짜, 좌우는 트랙 |
| 기간 바꾸기 | 카드 **위** 가장자리를 끌면 시작일, **아래** 가장자리를 끌면 종료일이 움직입니다 |
| 여러 트랙에 걸치기 | 카드 **오른쪽** 가장자리를 옆 트랙으로 끕니다(칸 단위). 편집 창의 **소속 트랙**에서 떨어진 트랙도 고를 수 있습니다 |
| 펼쳐 보기 | 안에 카드를 품은 카드를 **더블클릭**하면 그 안이 하나의 보드처럼 펼쳐집니다. 위쪽 경로를 눌러 돌아옵니다 |
| 복사·붙여넣기 | 카드 **우클릭 › 이벤트 복사**, 빈 칸 **우클릭 › 여기에 붙여넣기**. 안의 카드까지 새로 만들어지고, 다른 보드에도 붙습니다 |
| 보드에서 빼기 | 카드를 고르고 `Delete`(또는 `Backspace`). 안의 카드째 빠지고, 어디에도 없게 되면 **휴지통**으로 갑니다. 방금 만든 것은 그냥 사라집니다 |
| 되돌리기 | `Ctrl+Z` · 다시 실행 `Ctrl+Shift+Z` |

## 편집 창 (카드를 누르면 오른쪽에 열림)

탭은 **속성 · 매핑 · 스타일 · 상세** 넷입니다. 탭을 끌어 순서를 바꾸면 이 PC에 기억되고, 다른 카드를 눌러도 보던
탭이 그대로 열립니다. 창의 왼쪽 가장자리를 끌면 폭이 바뀌고, 오른쪽 위 압정을 켜면 `Esc`로도 닫히지 않습니다.

### 속성
제목(줄바꿈은 `Shift+Enter`) · 상태 · 유형(기간/마일스톤) · 담당 · 시작·종료 · 소속 트랙 · 비고.
마일스톤은 시작과 종료가 같으면 얇은 표식, 다르면 기간이 있는 막대로 그려집니다.

### 매핑 — 다른 일정과의 연결
각 항목의 **편집**을 누르면 고르는 창이 뜹니다. 창은 제목을 잡고 끌어 옮길 수 있고, 검색으로 찾을 수 있습니다.

| 항목 | 하는 일 |
|---|---|
| **항등설정** | 다른 보드에 따로 만든 같은 일정을 **하나로 합칩니다**. 어느 쪽 제목·상태·날짜를 남길지 고르고, 합친 직후 알림에서 되돌릴 수 있습니다 |
| **조합설정** | 이 일정이 **다른 보드의 여러 일정으로 이루어졌다**고 정합니다(둘 이상). 조합한 것은 보드에 카드로 그리지 않고 상세 탭에서 봅니다 |
| **모자관계설정** | **부모 설정**에서 이 카드를 품을 카드를, **자식 설정**에서 이 카드 안에 넣을 카드들을 한꺼번에 고릅니다. 같은 트랙 안의 카드만 고를 수 있습니다 |
| **선행관계설정** | 먼저 끝나야 하는 일정을 고릅니다. 보드에 화살표로 이어집니다 |

### 스타일 — 이 보드에서의 모습
- **채우기** — 카드 면 색(없음 + 8가지). 왼쪽 상태 막대는 그대로 보입니다.
- **글자 세로 정렬** — 위/가운데/아래.
- **비고 표시** — 속성 탭의 비고를 카드 위에 보일지. 기본은 숨김.
- **사이즈 수동 설정** — 켜면 날짜와 상관없이 좌·우 가장자리로 폭, 아래 가장자리로 높이를 끌어 정합니다. 끄면 자동 크기로 돌아옵니다.

### 상세
- **태스크** — 이 일정을 끝내려고 할 일 목록(체크리스트). 끝낸 비율이 진척률이 됩니다. ↑로 하위 카드로 올리고,
  하위 카드는 ↓로 태스크로 내릴 수 있습니다.
- **세부내역** — 조합한 일정이 있으면 그것과 그 안의 일정을, 없으면 이 카드 안의 하위 카드를 보여 줍니다.

## 트랙·설정

- 도구 모음 **설정**(또는 트랙 머리 오른쪽 **+**)에서 트랙을 추가·이름 변경·조합·빼기 합니다.
- 트랙 머리를 **좌우로 끌면** 순서가, 머리 **오른쪽 가장자리**를 끌면 폭이 바뀝니다(더블클릭하면 자동 폭).
- 트랙을 빼면 그 트랙에만 있던 일정이 함께 휴지통으로 가고, 다른 트랙에도 있던 일정은 남습니다.
- **담당 조직** — 추가·이름 변경·삭제. 이름을 바꾸면 그 조직이 맡은 일정도 함께 바뀝니다.
- **상태 이름** — 계획·진행중·완료·지연·보류를 이 보드에서 부를 이름. 색과 의미는 그대로입니다.
- **표시** — 화살표 굵기·머리 크기, 글자 크기 등.

## 왼쪽 달력 칸

- 월 칸을 **세로로 끌면** 여러 달을 한 칸으로 묶고 이름을 붙입니다(예: 1~3월 → `2027 1Q`).
- 칸 **아래 가장자리**를 끌면 그 구간의 높이가 줄거나 늘어납니다(안의 일정도 함께).
- 칸을 **우클릭**하면 이름 변경 · 해제 · 이 칸 접기 · 이 아래 빈 구간 삭제.

## 찾기·거르기·보기

- **일정 검색**(`Ctrl+F`) — 맞는 일정만 또렷하게 남습니다.
- **행 높이** — 축소/기본/확대. **글자 크기** — 가−/가＋ 또는 `Ctrl` `+` / `-` / `0`.
- **글자 선택 모드**(`Ctrl+I`) — 카드 글자를 긁어 복사할 수 있습니다. 켜 있는 동안은 카드를 끌어 옮기지 않습니다.

## 그래프

모든 보드의 일정을 **원**으로, 포함·선행 같은 연결을 **선**으로 한 화면에 보여 주는 탭입니다. 보기 전용이라 여기서
무엇을 해도 일정은 바뀌지 않습니다.

- 원이 클수록 그 안에 든 일정이 많습니다. 선 색은 포함(회색)·선행(파랑)·원인·참조(점선)입니다.
- **구조 중력**을 올리면 품는 쪽이 위로, **흐름 중력**을 올리면 앞선 일정이 왼쪽으로 정렬됩니다. 0이면 방향 없이 퍼집니다.
- 휠로 확대, 빈 곳을 끌어 이동, 원을 끌어 잠시 옮길 수 있습니다. **맞춤**을 누르면 전체가 보입니다.
- 원에 마우스를 올리면 이어진 일정과 연결 이름이, 누르면 오른쪽에 정보가 나옵니다.
- **관계 없는 이벤트 숨기기**로 아무 데도 이어지지 않은 일정을 감춥니다.

## 휴지통

보드에서 빼서 어디에도 놓이지 않은 일정이 모입니다. 첫 화면 오른쪽 위 휴지통 아이콘을 누르면 창이 뜹니다.
**영구 삭제**는 하나씩, **비우기**는 전부 지웁니다. 지우면 되돌릴 수 없고, 다른 보드에도 있는 일정은 남습니다.

## 저장·데이터·내보내기

- 편집은 자동 저장됩니다. **데이터 › 변경 이력**에서 이전 시점으로 되돌릴 수 있습니다.
- **데이터** — 보드를 JSON 파일로 **반출**하거나 **반입**합니다. 다른 사람과 보드를 주고받을 때 씁니다.
  표시 기간을 바꾸거나 **여백 자르기**로 일정 범위에 맞출 수 있습니다.
- **내보내기** — 보드 전체를 PNG(2배 해상도) · PDF(한 장) · 인쇄로 뽑습니다.
- 데이터는 이 PC의 `%APPDATA%\wolfpack\wolfpack.db`에 저장됩니다. 메뉴 **파일 › DB 파일 위치 열기**로 폴더를 엽니다.
