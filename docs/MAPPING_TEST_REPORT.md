# 매핑(동일·조합) 모델 정리 + 검증 보고서

날짜: 2026-09-27
대상: 이벤트 사이의 **동일(same)** · **조합(combine)** 매핑, 그리고 이름 보존.

## 1. 확정한 모델

이벤트는 전역 유일 키를 가진다. **이름이 곧 그 이벤트의 제목이며, 별칭은 없다.**
이름을 다른 이벤트로 복사·덮어쓰기·전파·동기화하지 않는다.

- **동일(same)** — "이 이벤트들은 서로 같은 것"이라는 대칭 관계. 자기 자신은 동일
  목록에 **항상 체크**로 보이며, 눌러도 풀리지 않는다(정체성). 각 이벤트는 자기 이름을
  그대로 지킨다.
- **조합(combine)** — "이 이벤트는 다른 이벤트들의 합"이라는 방향 관계. 부품을 고른다.
- 둘은 **완전히 별개의 관계**다. 동일 목록은 same만, 조합 목록은 combine만 만든다.
  (예전의 "고른 수로 1개=동일 / 2개 이상=조합" 방식은 폐기.)

## 2. 모순(contradiction) 처리 방식

구조상 '서로 다른 이벤트'로 증명된 것은 동일이 될 수 없다. 두 곳에서 막는다.

**(a) UI 후보에서 미리 제외** — `ItemPanel#sameExcluded`
- 자기 자신, 자기(가 홈인) 트랙, 조상·자손, **조합으로 엮인 상대**를 동일 후보에서 뺀다.
- `#combineExcluded`: 자기·동일 무리·조상·자손을 조합 후보에서 뺀다.

**(b) 로드 시 데이터 자가 정리** — `schema.js#normalizeRelations`
옛 데이터에 남아 있을 수 있는 모순을 로드할 때 스스로 버린다.
1. **동일 ∩ 조합**: 같은 쌍이 동일이면서 조합이면 → 조합을 남기고 동일을 버린다
   (조합이 더 구체적인 주장).
2. **동일 ∩ 포함(상하위)**: 두 끝이 contain 그래프로 조상↔자손이면 동일을 버린다
   (상위 일정과 그 안의 카드가 '같은 이벤트'라는 건 모순).
3. **조합 순환**: combine은 acyclic — 순환을 만드는 조합은 버린다.

## 3. 이름 보존 — 파괴적 동작 전부 제거

- `ItemPanel`의 `#applyLinks`(대상 본질을 카드에 복사) — **삭제**. 이름 흔들림의 원인.
- `schema.js`의 `propagateSame`(동일 무리끼리 제목·상태 맞춤) — **삭제**.
- 제목 입력은 이 카드에만 반영, 다른 이벤트로 전파하지 않는다.
- `alias`(별칭) UI·표시 — **삭제**. 카드 라벨은 항상 `item.ti`.
- 탭 간 실시간 반영(`tabs.js#syncFromActive`)은 **같은 id(동일 이벤트를 여러 보드에 배치)**
  에만 적용. 동일(same) 관계로 묶인 다른 이벤트는 각자 이름을 지킨다.

## 4. 상세(구성) 탭

이 이벤트를 이루는 것을 한 트리로 보여 준다 — 표시 UI를 하나로 통일(조합 기준).
- 같은 보드 하위 카드 + 이 이벤트 자신이 품은 카드(`eventCards`) + **동일/조합**으로 엮은
  이벤트의 카드(부품별 접기 그룹).
- 매핑을 바꾸면 즉시 다시 그린다(`#toggleSame`/`#toggleCombine` → `#renderChildren`).

## 6. 실제 DB 점검·정리

읽기 전용 복사로 진단 후, 원본 DB는 **백업 뒤** 정리.

- 예전에 의심했던 '카드-트랙 id 병합(이름 흔들림)'은 **현재 데이터에 없음**.
  `track:2:t3`("사각지대 이상감지")는 하나의 깨끗한 이벤트로, 보드 2(트랙)와 보드 1
  (트랙 "3D 셔틀 모니터링 시스템" 안의 중첩 참조)에 정상적으로 함께 놓여 있다(§3.4).
- **모순 1건 발견·삭제**: `same track:2:t3 → emuio38064`
  ("사각지대 이상감지" ↔ 그 트랙의 **자식 카드** "이상감지 모델 개발"). 상위↔자식은 동일이
  될 수 없어 삭제. 위 §2-(b)-2 규칙으로 앞으로는 로드 때 자동 정리된다.
- 정리 후: 무결성 `ok`, FK 위반 0, 관계 34건(전부 dep), same/combine 0건 — 깨끗한 상태에서
  올바른 매핑을 다시 쌓을 수 있다.
- 백업 위치(세션 스크래치패드): `wolfpack.backup-20260927-041627.db`.
