# 세로축 눈금 설계 — 보드별 눈금 모드와 날짜 없는 보드

> 개념 기준은 [SYSTEM.md](./SYSTEM.md)다: **순서가 먼저, 달력은 그 위에 얹는 눈금(표현)**, 날짜는 이벤트의
> **선택** 속성. 이 문서는 그 원칙을 보드 화면의 세로축에 옮긴다. 2026-09-28 사용자 결정으로 정했다.

## 1. 결정 (사용자 확인)

| 항목 | 결정 |
|---|---|
| 눈금 모드 | 보드마다 **주-일 · 월-주(기본) · 분기-월 · 눈금 없음** 중 하나. 표현이라 이벤트 데이터는 안 바뀐다 |
| 시·분 | 지금은 없음. 한 칸 단위에 나중에 더할 자리만 둔다 |
| 날짜 있는 보드를 '눈금 없음'으로 | 날짜 표시만 사라지고 일정은 그 칸에 그대로. **한 칸 = 전환 전 모드의 안쪽 단위**(월-주였다면 1주) |
| 날짜 없는 보드 | 처음부터 눈금 없이 만든다. 일정에 **날짜가 없고 순서(칸)만** 있다 — (나)안 |
| 날짜 없는 보드에 눈금 입히기 | 일괄 설정 — **한 칸의 단위(일·주·월·분기)** 와 **1번 칸의 날짜**를 고르면 모든 일정이 날짜를 얻는다 |
| 구간 묶기·높이 | 각 모드의 **바깥 칸**에 적용(주-일=주, 월-주=월, 분기-월=분기). **모드별로 따로 기억** |
| 드래그 정밀도·새 일정 길이 | 주-일 1일·1일 / 월-주 1일·1주 / 분기-월 1주·1개월 / 눈금 없음 1칸·1칸 |
| 순서 축(초안) | 없앤다 — 쓰지 않는 기능, 눈금 없음이 대신한다 |

## 2. 두 가지 보드

| | 날짜 있는 보드 (`display.dated = true`) | 날짜 없는 보드 (`display.dated = false`) |
|---|---|---|
| 세로 위치의 근거 | 이벤트 본질의 **날짜**(`s`·`e`) | 이 보드 배치의 **칸**(`place.slot = {s, len}`) |
| 눈금 모드 | 주-일 · 월-주 · 분기-월 · 눈금 없음(보기만) | 눈금 없음뿐 |
| 이벤트 날짜 | 있다 | 없다(`null`) — SYSTEM.md "날짜는 선택" |

- 칸은 **배치**(표현)다. 같은 이벤트가 두 날짜 없는 보드에 있으면 칸도 보드마다 다르다(SYSTEM.md §6 "순서 위치").
- 날짜 있는 보드의 '눈금 없음'은 **보기 방식**일 뿐이다 — 근거는 여전히 날짜. 칸 번호는 날짜에서 계산한다
  (`display.slotUnit` = 전환 전 안쪽 단위). 끌면 한 칸(=그 단위)씩 날짜가 움직인다.
- 날짜 없는 보드에 눈금을 입히면(일괄 설정) 칸 → 날짜로 바뀌고 날짜 있는 보드가 된다. 되돌리기 1단계.

## 3. 모드 정의 (`config SCALE_MODES`)

| 모드 | 바깥 칸 | 안쪽 칸 | 한 행(줌 높이)이 뜻하는 것 | 드래그 정밀도 | 새 일정 |
|---|---|---|---|---|---|
| `week-day` 주-일 | 주 | 일 | 1일 | 1일 | 1일 |
| `month-week` 월-주 | 월 | 주 | 1주 | 1일 | 1주 |
| `quarter-month` 분기-월 | 분기 | 월 | 1개월 | 1주 | 1개월 |
| `none` 눈금 없음 | — | 칸 번호 | 1칸 | 1칸 | 1칸 |

줌(축소·기본·확대)은 **한 행 높이**다. 모드마다 한 행이 뜻하는 단위가 달라, 일당 픽셀은 모드가 정한다.

## 4. 저장

- 표시 설정 `meta.display`(보드 `meta_json`): `scale`(모드), `dated`, `slotUnit`. 옛 `axis`·`axisDir`은 버린다.
- 구간 `doc.bands[].mode` — 어느 모드의 바깥 칸 묶음인가. DB `band.mode`(021). 옛 구간은 `month-week`.
- 칸 `item.place.slot` — DB `disp.slot_start`·`slot_len`(021). 날짜 없는 보드에서만 쓴다.
- 이벤트 날짜 NULL 허용 — DB `event.start_date`·`end_date`의 NOT NULL을 푼다(021, 테이블 다시 만들기).
- 문서 v18: 위를 정규화. 날짜 없는 보드는 날짜를 채우지 않는다(날짜 있는 보드는 지금처럼 채운다).

## 5. 계산 — 위치 한 가지로

보드 코드는 달력인지 칸인지 모르고 **위치 인덱스**만 다룬다(`core/timeline.js`).

- 날짜 있는 보드: 위치 = 일 인덱스(시작일부터 며칠). 스케일은 `TimeScale`(모드의 일당 픽셀·구간 배율).
- 날짜 없는 보드: 위치 = 칸 인덱스. 스케일은 `SlotScale`(한 칸 = 한 행).
- 정밀도 단위(`step`: 일·주·월·칸)로 **맞추기·더하기·차이**를 계산한다 — 월은 달력 산술(말일 보정).
- 레인 배치·드래그·만들기·붙여넣기·세부 표시가 모두 이 한 곳을 거친다.

## 6. 화면

- 설정 › 표시에 **눈금** 고르기. 날짜 없는 보드는 '눈금 없음' 고정 + **눈금 설정…**(일괄 변환).
- 새 보드를 만들 때 눈금을 고른다(월-주 기본 · 주-일 · 분기-월 · 눈금 없음 = 날짜 없는 보드).
- 눈금 없음: 안쪽 칸에 칸 번호, 오늘선·구간 묶기 없음, 카드에 날짜 대신 칸 번호.
- 날짜 없는 보드의 편집 창: 시작·종료 대신 **칸 위치·길이**.

## 7. 구현 메모

- DB 021은 `event`를 새로 만든다(NOT NULL 풀기). 옛 테이블은 지우지 않고 `event_v20`으로 이름만 바꿔 둔다 —
  DROP하면 옛 이관용 `placement`·`event_task`(010)가 ON DELETE CASCADE로 비워지기 때문이다. 읽는 코드는 없다.
- 날짜 있는 보드의 '눈금 없음'에서 칸 번호는 보드 시작일이 든 단위를 1번으로 센다(주는 월요일 시작).
- 눈금 설정(일괄)은 보드의 **모든** 일정 날짜를 칸 위치로 다시 쓴다. 다른 보드와 공유한 이벤트면 그 보드에서도
  날짜가 바뀐다(날짜는 본질). 되돌리기 1단계.
- 복사·붙여넣기는 같은 종류 보드(날짜↔날짜, 칸↔칸)끼리 상대 위치를 지키고, 종류가 다르면 붙이는 자리에 기본 길이로 놓는다.
- 스모크: `scale`(모드 전환·정밀도·새 일정 길이·모드별 구간·날짜 보존) · `dateless`(칸 저장·NULL 날짜·다시 읽기·눈금 설정·되돌리기).
